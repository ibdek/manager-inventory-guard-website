Customer journey

Onboarding sequence

Inventory Guard removes several manual setup steps. The customer creates only the bootstrap Inventory Setup & Synchronisation Custom Button; Inventory Guard handles the remaining required control setup after the business is linked.

Important: the one-time Inventory Guard linking code and the Manager Access Token Secret are different credentials. Inventory Guard does not require the customer's Manager.io login password.
1

Register the business

Open the Inventory Guard Start page and register the Manager.io business. One customer account may own multiple Manager businesses, but each business is a separate Inventory Guard tenant.

2

Generate a linking code

Sign in to the Customer Portal, select the business and generate its single-use linking code. The current linking-code validity is 30 minutes.

3

Create the one bootstrap button

In Manager.io, create Inventory Setup & Synchronisation under Settings and point it to https://inventoryguard.adib.com.ng/extension/location-sync.

4

Link the correct business

Open Inventory Setup & Synchronisation inside that Manager business and enter the one-time linking code.

5

Save the Manager service connection

Create an authorised Manager Access Token, then save the business API2/base URL and token in Inventory Guard. The token is protected and the Manager login password is not required.

6

Click Complete Setup

Inventory Guard secures the business binding, detects inventory mode, synchronises inventory and locations, creates or refreshes today's Inventory Quantity by Location report when needed, and creates or updates the required controlled Custom Buttons.

7

Initialise integrity protection

Open the Control Centre and review existing Manager records before initialising the Bypass & Integrity Monitor baseline.

8

Configure restricted users if required

An authorised/full-access Manager administrator refreshes users and Divisions from the Control Centre. The Customer Portal OWNER then assigns allowed Divisions and Inventory Locations before enabling User Access Control.

After setup: users work through Controlled Sales Invoice, Controlled Cash Sale Receipt and, for multi-location businesses, Controlled Inventory Transfer. Later location, Division or Manager-user changes are normally reconciled automatically when an authorised administrator opens the Control Centre. Synchronise & Repair Setup is now a recovery/maintenance tool, not a routine step.
User access control

Keep restricted users inside their assigned operating scope

Inventory Guard can align restricted Manager users with specific Divisions and Inventory Locations. Full-access Manager users remain privileged.

  • Refresh Manager users and Divisions from the Control Centre
  • Assign permitted Divisions and Inventory Locations in the Customer Portal
  • Preserve existing restricted-user assignments during later refreshes
  • Do not silently grant newly discovered Divisions or Locations to restricted users
  • Enable access control only after assignments are ready
Open Control Centre User Access Setup
Structure changes are handled automatically

What happens later?

If a business starts without custom Inventory Locations or Divisions and adds them later, an authorised administrator can simply open the Inventory Guard Control Centre.

Inventory Guard reconciles the current structure, preserves existing restricted-user assignments and introduces the Inventory Transfer workflow automatically when the business changes from single-location to multi-location operation.

Normal operating flow

Use the controlled transaction entry points

The controls remain inside the Manager.io workflow while Inventory Guard performs the required validation first.

1

Sales Invoice

Open Controlled Sales Invoice, select the transaction details, and let Inventory Guard validate stock, credit and protected pricing before creation in Manager.

2

Cash Sale Receipt

Use Controlled Cash Sale Receipt for cash sales so the quantity check happens before the Manager Receipt is created.

3

Inventory Transfer

Multi-location businesses use Controlled Inventory Transfer. Source location is controlled and destination selection remains within the permitted scope.

4

Monitor integrity

Review bypass and integrity exceptions for covered records created directly in Manager or changed after controlled creation.

5

Refresh structure normally

When locations, Divisions or users change, an authorised administrator opens the Control Centre to trigger the normal reconciliation path.

6

Maintain access

The Customer Portal OWNER reviews any newly discovered scope and grants it deliberately to restricted users where appropriate.
