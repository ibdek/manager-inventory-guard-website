Self-start business onboarding

Start the 10-transaction free trial directly from Manager.io

For a new business, no linking code is required. Create one bootstrap Custom Button, open it inside the correct Manager business, and Inventory Guard verifies and registers the business directly.

Important: Inventory Guard needs an administrator-level Manager Access Token Secret, not the customer's Manager.io login password. The normal self-start path does not require a one-time linking code; linking codes remain available for already-registered businesses and Assisted Onboarding.
1

Create the bootstrap button

In the Manager business, create a Custom Button named Inventory Setup & Synchronisation under Settings and point it to https://inventoryguard.adib.com.ng/extension/location-sync.

2

Open it inside Manager

Open Inventory Setup & Synchronisation from the exact Manager business you want to protect. Inventory Guard uses the in-business context to establish the secure installation.

3

Register the business

Enter the Manager API2 endpoint, administrator-level Access Token Secret, contact name, email and phone, then click Register Business & Start Free Trial.

4

Automatic secure binding & trial

Inventory Guard verifies the Manager API2 connection, creates the tenant and secure business installation binding, and activates the 10-successful-transaction free trial automatically.

5

Complete Setup

Click Complete Setup. Inventory Guard detects single- or multi-location operation, synchronises inventory and locations, creates or refreshes the required stock report where needed, and installs or repairs the controlled Custom Buttons.

6

Review print themes

Choose Manager's default theme or the required Custom Theme for Sales Invoices and cash-sale Receipts so controlled transactions use the intended print presentation.

7

Initialise integrity protection

Open the Control Centre and review existing Manager records before initialising the Bypass & Integrity Monitor baseline.

8

Configure restricted users if needed

An authorised/full-access Manager administrator opens User Access Setup, refreshes active Manager users and Divisions, assigns permitted Divisions and Inventory Locations, and enables User Access Control when assignments are ready.

Already registered or Assisted Onboarding? Open the same Inventory Setup & Synchronisation page and use Link Existing Business with the supplied one-time linking code. After setup, ordinary users work through the controlled transaction pages only. Restricted operational users do not receive a Back to Inventory Guard Control Centre route. Later Manager-user, Division and Inventory Location changes are reconciled when an authorised administrator opens the Control Centre. Synchronise & Repair Setup remains a recovery/maintenance tool rather than a routine step.
User access control

Keep restricted users inside their assigned operating scope

Inventory Guard can align restricted Manager users with specific Divisions and Inventory Locations. Full-access Manager users remain privileged.

  • Refresh active Manager users and Divisions from the Control Centre; removed/inactive Manager users are excluded from User Access Setup
  • Assign permitted Divisions and Inventory Locations from User Access Setup inside the Manager business
  • Preserve existing restricted-user assignments during later refreshes
  • Do not silently grant newly discovered Divisions or Locations to restricted users
  • Enable access control only after assignments are ready
  • Restricted operational users stay inside the controlled transaction pages and are not given a Back to Inventory Guard Control Centre navigation route
Structure changes are handled automatically

What happens later?

If a business starts without custom Inventory Locations or Divisions and adds them later, an authorised administrator can simply open the Inventory Guard Control Centre.

Inventory Guard reconciles the current structure, preserves existing restricted-user assignments and introduces the Inventory Transfer workflow automatically when the business changes from single-location to multi-location operation.

Normal operating flow

Use the controlled transaction entry points

The controls remain inside the Manager.io workflow while Inventory Guard performs the required validation first.

1

Sales Invoice

Open Controlled Sales Invoice, select the transaction details, and let Inventory Guard validate stock, credit and protected pricing before creation in Manager.

2

Cash Sale Receipt

Use Controlled Cash Sale Receipt for cash sales so the quantity check happens before the Manager Receipt is created.

3

Inventory Transfer

Multi-location businesses use Controlled Inventory Transfer. Source location is controlled and destination selection remains within the permitted scope.

4

Monitor integrity

Review bypass and integrity exceptions for covered records created directly in Manager or changed after controlled creation.

5

Refresh structure normally

When locations, Divisions or users change, an authorised administrator opens the Control Centre to trigger the normal reconciliation path.

6

Maintain access

An authorised administrator reviews newly discovered scope in User Access Setup inside the Manager business and grants it deliberately to restricted users where appropriate.

Annual subscription workflow

Pay through Selar and keep the verification trail clear

The live subscription workflow distinguishes payment from payment verification so annual access can be administered safely.

1

Open Subscription

Inside the linked Manager business, open Inventory Guard Control Centre → Subscription. Review trial usage, annual fee, expiry and current access.

2

Click Subscribe Now

For an eligible business, click Subscribe Now to open the configured Selar checkout and complete the annual payment.

3

Return and submit the Selar reference

After payment, return to Inventory Guard and submit the genuine Selar receipt/order/payment reference. A customer-submitted reference receives provisional annual access while administrator verification is pending.

4

Administrator verifies payment

The administrator checks the reference against the Selar dashboard and marks it verified. Pending customer claims have a 72-hour verification window.

5

If the return form was missed

If payment succeeded but the customer did not submit the return form, or submitted an incorrect reference, contact support by WhatsApp or email. After independently confirming the payment in Selar, the administrator can record a verified Selar override without treating it as a bank-transfer payment.

6

Renew or transfer where applicable

Active annual businesses can renew from the Subscription page. If a Manager business is permanently replaced, eligible unused annual access can be transferred to a fully onboarded replacement business while preserving the original paid-through date.

Payment safety: an administrator override bypasses only the missed/incorrect customer return form; it does not bypass payment verification. The payment must first be confirmed independently in the Selar dashboard.
